# Правила защиты методик ZharikovApp

## 1. Что защищено (не менять НИ ПРИ КАКИХ УСЛОВИЯХ)
- `docs/methodics_source.md` — эталонный источник методик (в задачах также именуется source_methodologies.md), только чтение.
- Тексты вопросов, формулировки, порядок, нумерация, количество, id и order блоков.
- Внутренние значения вариантов ответов (`key`/`value`), их порядок и количество.
- Ключи, веса, формулы, пороги, шкалы, правила определения уровня по баллам.
- Поведение логики подсчёта: `Services/ScoringService.cs`, модели `Models/*Scoring*`, `Enums.cs`, `Question.cs`, `AnswerOption.cs`, `ScaleConfig.cs`, `InterpretationRule.cs`.
- Данные блоков: `Data/Blocks/block_01 … block_12 *.json`.

Косметические поля (`displayLabel`, `letter` и т.п.) в данных разрешены, но НЕ входят в смысловой слепок и не влияют на расчёт.

## 2. Что разрешено менять
Внешний вид, разметку, размеры, шрифты, цвета, анимации, навигацию, клавиатурное управление, окна и диалоги, показ результатов, экспорт, работу с изображениями, структуру папок без изменения защищённых данных, комментарии в коде.

## 3. Что запрещено
- Додумывать, добавлять, удалять или сокращать вопросы; перефразировать методики.
- Менять буквы/цифры внутренних значений ответов, ключи, веса, формулы, пороги.
- Менять поведение подсчёта «на более правильное».
- Молча пропускать ошибки загрузки и подсчёта.
- Выполнять несколько крупных задач за один шаг.

## 4. Как запустить проверку
```powershell
powershell -ExecutionPolicy Bypass -File tools/guard_check.ps1
```
Проверка: хэши → смысловой слепок → число блоков/вопросов → контрольные векторы кодом приложения → отчёт `docs/guard_report.md`. Код выхода 0 = зелёная.

## 5. Как выполнить откат
```powershell
powershell -ExecutionPolicy Bypass -File tools/guard_restore.ps1
```
Восстанавливает только защищённые файлы из `tools/baseline/backup/`, предварительно создавая emergency-копию текущего состояния; пишет протокол в `docs/restore_log.md`. Пользовательские результаты и сессии не удаляются.

## 6. Что делать при красном отчёте
1. Остановить работу.
2. Выполнить `guard_restore.ps1`.
3. Снова выполнить `guard_check.ps1`.
4. Если снова красный — сообщить пользователю, ничего не «чинить» самостоятельно.

## 7. Обязательные правила процесса
- После каждого изменённого шага запускать `tools/guard_check.ps1`.
- Не переходить к следующим UI-промтам, пока защита не зелёная.
- При любом расхождении с эталоном — немедленный откат и остановка.
- Эталон обновляется ТОЛЬКО по явной команде пользователя после легальной смены источника.
